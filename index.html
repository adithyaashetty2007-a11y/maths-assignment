Proving things about harmonic numbers by induction

Build each proof one step at a time: base case, induction hypothesis, inductive step. Then test claims yourself and solve the exercises.

Definitions

Harmonic number

For an integer n ≥ 1, the n-th harmonic number is the sum of the first n reciprocals:

Hn = 1 + 1/2 + 1/3 + … + 1/n

We also define H0 = 0 (an empty sum).

The recurrence

Hn+1 = Hn + 1/(n+1)

Adding one more term gives the next harmonic number. Every proof below uses this fact in the inductive step.

Mathematical induction

To prove that P(n) is true for all n ≥ n₀:

Base case. Show P(n₀) is true.
Induction hypothesis. Assume P(k) is true for some k ≥ n₀.
Inductive step. Using that assumption, show P(k+1) is true.

The base case starts the chain and the step passes truth from each number to the next, like dominoes.

See induction as dominoes

The gold domino is the base case. The inductive step says: if domino k falls, domino k+1 falls too. Together, every domino falls.

Why harmonic numbers matter

The terms 1/k shrink to zero, yet Hn grows past every bound, only very slowly (about ln n). The first claim in the Proof lab shows this using induction.

Using the recurrence

Notice that H4 ≈ 2.083 is already larger than 2. Keep this in mind for the Experiment tab.

A sum of harmonic numbers

H1 + H2 + H3 = 1 + 3/2 + 11/6 = 6/6 + 9/6 + 11/6 = 26/6 = 13/3.

Now try the formula (n+1)Hn − n at n = 3: 4 · 11/6 − 3 = 22/3 − 3 = 13/3. Both sides match, which is exactly what Claim B says. The Proof lab shows why this works for every n.
